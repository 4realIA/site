# 4ia.info

Andy Anton's personal site. Plain HTML and CSS, no build step, served by GitHub Pages.

- `index.html` – the page
- `styles.css` – all styling (light and dark follow the system setting)
- `CNAME` – the custom domain; change this one line to move to a new domain
- `privacy.html` – what the site and each app collect and connect to; update it (and its date) when an app starts talking to something new
- `og.png` – the preview image LinkedIn and others show for links

Edit, commit, push to `main`; the site updates in about a minute.
